# Browser Panel Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** A workspace panel that streams the agent's `agent-browser` session live, lets the user interact, manages persistent named browsers with a shared `default`, keeps subagents in throwaway browsers, and ships a skill that teaches agents the rules.

**Architecture:** A bash shim on the agent's PATH routes every `agent-browser` call into `~/.cogpit/browser/` (per-name persistent profile, Cogpit-owned socket dirs, `--remote-debugging-port=0`). The server attaches to Chromium over CDP through `<profile>/DevToolsActivePort`, screencasts the followed tab and injects input, and exposes it on a `/__browser` WebSocket beside `/__pty`. A React panel renders frames on a canvas and maps pointer/keyboard events back. Design: `docs/plans/2026-09-06-browser-panel-design.md`.

**Tech Stack:** Node 24 / `ws` (already a dependency), Vite + React 19, Tailwind v4, base-ui primitives in `@/components/ui/*`, vitest + Testing Library. Use `bun`, never `npm`.

**Working directory:** `/Users/gentritbiba/agent-window/.worktrees/browser-panel` (branch `browser-panel`). All paths relative to it.

**Conventions for every task:**
- TDD: write the failing test, run it, implement, run again, commit.
- Run a single file with `bunx vitest run <path>`. Run `bun run lint` before each commit.
- No `Co-Authored-By` lines. Never push.
- Delete anything a task makes unused.
- `server/browser/**` and `shared/browser/**` never name an agent CLI ("claude", "codex", "copilot") so `bun run check:agents` stays green.
- Tests that touch `~/.cogpit/browser` must set `process.env.COGPIT_BROWSER_HOME` to a temp dir in `beforeEach` and delete it in `afterEach`.

### Task 2: Shim script

**Files:**
- Create: `server/browser/shim.ts`
- Test: `server/__tests__/browser/shim.test.ts`

`SHIM_VERSION = 1`. `renderShim(realBinary: string): string` returns:

```bash
#!/usr/bin/env bash
# cogpit-shim v1 — routes agent-browser into Cogpit's managed browser tree.
# Regenerated by Cogpit on start; edits are lost.
set -euo pipefail
real="<realBinary>"
home="${COGPIT_BROWSER_HOME:-$HOME/.cogpit/browser}"
name="${AGENT_BROWSER_SESSION:-default}"
prev=""
for arg in "$@"; do
  if [ "$prev" = "--session" ]; then name="$arg"; break; fi
  case "$arg" in --session=*) name="${arg#--session=}"; break;; esac
  prev="$arg"
done
case "$name" in
  *[!a-z0-9_-]*|"") exec "$real" "$@";;
esac
if [[ "$name" == tmp-* ]]; then
  sid="${COGPIT_SESSION_ID:-shared}"
  case "$sid" in *[!A-Za-z0-9_-]*|"") sid="shared";; esac
  export AGENT_BROWSER_SOCKET_DIR="$home/run/$sid"
  mkdir -p "$AGENT_BROWSER_SOCKET_DIR"
  exec "$real" "$@"
fi
profile="$home/profiles/$name"
mkdir -p "$profile" "$home/run/shared"
printf '%s\n' "${COGPIT_SESSION_ID:-}" > "$profile/.driver"
export AGENT_BROWSER_SOCKET_DIR="$home/run/shared"
export AGENT_BROWSER_PROFILE="$profile"
export AGENT_BROWSER_ARGS="--remote-debugging-port=0"
exec "$real" "$@"
```

`ensureShim(realBinary: string | null): { path: string | null }`: when `realBinary` is null, remove an existing shim and return `{ path: null }`; else write the script (mode `0o755`) when missing or its first two lines differ, return `{ path }`.

`findRealAgentBrowser(env = process.env): string | null`: walk `PATH`, skip entries equal to `binDir()`, return the first executable `agent-browser`.

Tests run the rendered shim with `bash` against a fake binary (a temp script that prints `SESSION_DIR=$AGENT_BROWSER_SOCKET_DIR`, `PROFILE=${AGENT_BROWSER_PROFILE:-}`, `ARGS=${AGENT_BROWSER_ARGS:-}`, then `printf '[%s]' "$@"`):
1. no flags → profile `profiles/default`, socket `run/shared`, debugging arg, `.driver` contains `COGPIT_SESSION_ID`.
2. `--session github open x` → profile `profiles/github`, args echoed unchanged.
3. `--session=tmp-abc snapshot` with `COGPIT_SESSION_ID=s1` → socket `run/s1`, no profile, no args.
4. `AGENT_BROWSER_SESSION=work` env, no flag → profile `profiles/work`.
5. `--session 'Bad Name'` → passthrough (no profile, no socket dir).
6. arguments with spaces/quotes survive (`fill @e1 "hello world"`).
7. `ensureShim(null)` removes; `ensureShim(path)` writes executable file; rewriting only when version line changes (check mtime unchanged on second call).
8. `findRealAgentBrowser` skips `binDir()` and finds the fake binary on a synthetic PATH.

```ts
export interface ViewerEvents {
  frame(header: FrameHeader, jpeg: Uint8Array): void
  tabs(tabs: BrowserTab[], followed: string | null): void
  page(info: { targetId: string; url: string; title: string; canGoBack: boolean; canGoForward: boolean }): void
  closed(reason: string): void
}
export class BrowserViewer {
  static async open(browserWsUrl: string, events: ViewerEvents): Promise<BrowserViewer>
  setViewport(width: number, height: number, dpr: number): Promise<void>   // restarts screencast with maxWidth/maxHeight = css size * min(dpr, 2), capped 1920x1200
  follow(targetId: string): Promise<void>
  mouse(msg): Promise<void>       // Input.dispatchMouseEvent on followed session; "move"→mouseMoved, "down"→mousePressed, "up"→mouseReleased
  wheel(msg): Promise<void>       // type mouseWheel
  key(msg): Promise<void>         // Input.dispatchKeyEvent; "down" with text → type "keyDown" + text, else "rawKeyDown"; "up" → "keyUp"
  navigate(url): Promise<void>    // Page.navigate; prefix https:// when no scheme and not localhost-ish
  back()/forward(): Promise<void> // Page.getNavigationHistory → navigateToHistoryEntry
  reload(): Promise<void>
  close(): Promise<void>
}
```

Screencast starts on first `setViewport` and moves with `follow`.

Assertions: attach happens, frames emitted with decoded header, `follow` switches the sessionId used for input, `navigate("example.com")` sends `https://example.com`, `targetDestroyed` re-follows, `close` stops screencast and closes the socket.
