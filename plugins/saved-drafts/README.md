# Saved drafts

Install and enable Saved drafts from Plugins to save, swap, merge and recall messages in a plugin workspace. Ctrl/⌘+Shift+S saves and clears the active composer; ↑/↓ in an empty composer recalls the last 30 accepted sends. The workspace also offers restore, delete, backup and storage recovery controls.

The official package activates a lazy host-browser adapter even when its panel is closed. It requests the composer drafts permission. Only metadata and text excerpts enter the iframe; context snapshots and image bytes remain in the host browser. Explicit backup downloads the complete host-side record, including damaged raw storage when present.

Existing v1 composer records use their original keys and format. Installation reads only the active account/device/project/composer record; legacy data never installs or enables the plugin. Disable or uninstall removes the hooks and leaves all saved data in place. Without the plugin the composer offers live editing and an in-memory unsent-message recovery notice.
