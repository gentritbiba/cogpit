# @cogpit/plugin-integrations

Browser-safe ClickUp contracts and response normalizers shared by the compatibility adapter and independent ClickUp runtime package. These modules contain no transport, credentials, filesystem, application state or provider account defaults.

Import types from `@cogpit/plugin-integrations/clickup` and parsers from `@cogpit/plugin-integrations/normalizeClickUp`, or use the package root. Build JavaScript and self-contained NodeNext declarations with `bun run build`.
