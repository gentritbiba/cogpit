**Status:** PASS — no documentation drift

## Summary

Major refactor unified agent-specific knowledge behind `AgentDescriptor`, `AgentFormat`, `AgentStore`, and `AgentRuntime` abstractions. This moved per-agent branching out of routes, hooks, and components into dedicated `server/agents/` and `src/lib/agents/` modules. Per-agent registries replaced hardcoded if-else chains:

- `tailRecords.ts`, `summaryFolds.ts`, `usageScanners.ts`, `recordReaders.ts` — per-record interpretation tables
- `<agent>Metadata.ts`, `<agent>Models.ts` — agent-specific identity and model catalogs
- `<agent>Runtime.ts`, `<agent>Store.ts` — unified transport and file access interfaces
- `src/lib/agents/quota.ts`, `goals.ts`, `nativeRewind.ts`, `modelFallback.ts`, `models.ts`, `presentation.ts` — renderer wire readers and presentation

The event name `copilot_activity` was renamed to the agent-neutral `runtime_activity`, and `agentKindForDirName` was replaced with `descriptorForDirName` for descriptor-based lookups. Agent vocabulary check ratcheted: 163 files / 999 lines → 139 files / 510 lines.

Version bumped to 2.1.1.
