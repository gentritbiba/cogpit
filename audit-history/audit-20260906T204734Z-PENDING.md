# Browser screenshot recovery and 2.6.0 release audit

Status: PASS. Code review, simplification review and documentation audit approved.

Screenshots can reset the page viewport while leaving the viewer CDP session's emulation dimensions stale. The viewer now coalesces resize notifications, reads the actual page dimensions, and synchronizes its emulation state. External viewport choices remain intact and become the saved restoration dimensions. Closing or changing tabs invalidates delayed work.

Updated browser documentation and generated skill describe the new sizing behavior. Included pending guidance on short sequential browser action chains, observed references, session ownership and handoffs. App version is 2.6.0; release CI stamps the launcher version from the tag.

The launcher package contract now reads esbuild import metadata instead of treating strings in embedded browser instructions as package imports.
