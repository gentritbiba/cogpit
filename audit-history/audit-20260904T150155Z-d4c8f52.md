## Summary of Changes

This commit adds a new compile-time ClickUp workspace panel with personal API token authentication, workspace-wide task listing, and per-project task list linking:

1. **New ClickUp plugin** (`plugins/clickup/`):
   - Panel with two tabs: **My tasks** (workspace-wide, overdue-first) and **This project** (linked list with closed-fold)
   - Task filters: status, due date, priority, free-text search
   - List linking: paste ClickUp URL/ID or browse space → folder → list
   - Token setup screen with inline error handling
   - Expandable task rows with description, tags, "Add to prompt", and "Open in ClickUp"
   - Rail indicator: count of overdue tasks assigned to the user

2. **New server routes** (`server/routes/clickup.ts`):
   - `GET /api/clickup/status` — authentication status and user identity
   - `POST /api/clickup/token` — verify and persist personal API token
   - `DELETE /api/clickup/token` — forget the token
   - `GET /api/clickup/tasks/mine` — workspace-wide tasks assigned to viewer
   - `GET /api/clickup/tasks/list?cwd=` — tasks of project-linked list
   - `GET /api/clickup/spaces` — list workspaces' spaces
   - `GET /api/clickup/lists?spaceId=` — folders and lists within a space
   - `PUT /api/clickup/project-list` — link/unlink project to list

3. **New token configuration** (`server/lib/clickupConfig.ts`):
   - File: `~/.cogpit/clickup.json` (mode 600)
   - Environment overrides: `COGPIT_CLICKUP_TOKEN` or `CLICKUP_API_TOKEN`
   - Persistent project-to-list mappings

4. **Contract** (`shared/contracts/clickup.ts`):
   - Task entity: id, customId, name, description (markdown), status, priority, dates, assignees, tags, hierarchy
   - List, folder, space, and workspace names
   - Responses for status, tasks, lists, spaces
   - Error codes: `clickup_not_configured`, `clickup_auth_failed`, `clickup_api_failed`, `clickup_rate_limited`, `invalid_response`, `project_unlinked`

5. **Generic panel components promoted to plugin-api**:
   - `src/plugin-api/parts.tsx` — `ClosedFold`, `FilterBar`, `TabEmpty`, `CommentCount`
   - `src/plugin-api/Description.tsx` — markdown description rendering
   - `src/plugin-api/time.ts` — `duration`, `relativeTime`, `useNow` for timestamps
   - Exported from `src/plugin-api/index.ts` for reuse by other plugins

6. **Store and state management** (`plugins/clickup/clickupStore.ts`):
   - External-store pattern (same as GitHub plugin)
   - 8-second cache window, 60-second background polling
   - Setup errors do not poll
   - Token and link mutations trigger force-refresh
