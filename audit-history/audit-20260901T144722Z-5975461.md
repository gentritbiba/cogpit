# Pull request session search audit

**Date:** 2026-09-01 14:47 UTC
**Commit:** 5975461
**Status:** PASS after documentation updates

## Summary

Session search now recognizes exact pull request queries in the desktop sidebar and project Sessions page. Supported forms include `#157`, `honest-cms #157`, `honest-cms#157`, `PR 157`, and pasted GitHub pull request URLs. Results cover sessions that created a pull request or used an explicit `gh pr` action for it, and each matching row shows `Matched #157`.

The server builds a durable transcript index in the background rather than blocking the request on a full history scan. Clients poll while `X-Cogpit-PR-Index-Pending` is nonzero. Completed searches return `matchedPullRequestNumber` on each matched session.

## Compatibility

Normal text search keeps its existing behavior. Pull request search is additive. The response adds an optional `matchedPullRequestNumber` field, and the indexing progress headers only appear for recognized pull request queries.

The persistent index lives in Cogpit's session configuration directory and refreshes entries when a transcript's size or modification time changes.

## Conclusion

The feature needed a short user-facing discovery note and precise API documentation. Both are now present. No other parent-repository documentation describes session search syntax or the PR index, so no stale parent-repository guidance remains.
