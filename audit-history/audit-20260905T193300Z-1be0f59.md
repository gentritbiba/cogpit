## Contract changes

- New GET `/api/project-files/tree?cwd=&dir=&refresh=1` endpoint: returns a lazy folder tree `{entries: [{name, type:"file"|"directory"}], scanLimited}` with single-child directory chains collapsed (e.g., `packages/app/src` as one entry). Respects the same gitignore-aware file listing as the search endpoint.
- Model catalog refresh: replaced one-time per-page-load fetch latch with TTL-based refresh (5 minutes, 30 s retry after failure). New `refreshModelCatalogOnFocus()` hook auto-refreshes on window focus and visibilitychange events. AgentModelDropdown also triggers refresh on open. Improves experience on desktop where app stays open for days—CLI upgrades show new models within the TTL window.
