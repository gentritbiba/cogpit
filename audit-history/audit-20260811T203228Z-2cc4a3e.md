**Date:** 2026-08-11

**Scope:** Install-free npm launcher, reusable standalone server lifecycle, focused `/preview/:sessionId` renderer, local-only web assets, tests, and CI package verification.

## Contract-level changes

| Change | Documentation surface |
| --- | --- |
| `npx cogpit@latest` starts the full local Cogpit app without a prior installation or running Cogpit process. | Root README and package README |
| `npx cogpit@latest preview <session-id>` opens an existing Claude Code or Codex session in a chat-only view with the shared composer controls. | Root README and package README |
| The npm artifact bundles the renderer and canonical standalone backend, binds loopback on an available port, and shuts down on `Ctrl+C`. | Root README, package README, architecture guide |
| `server/standalone-runtime.ts` is now the shared lifecycle used by the headless entry point and install-free launcher. | Architecture ownership map and dependency rule |
| The npm tarball and runtime contract are exercised in Linux and Windows quality jobs. | Architecture required-gates section |
