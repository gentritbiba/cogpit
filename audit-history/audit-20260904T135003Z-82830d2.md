## Summary of Changes

This commit consolidates the GitHub Actions plugin into a general GitHub plugin and introduces per-session usage/cost tracking:

1. **GitHub plugin expansion** (`plugins/github-actions/` → `plugins/github/`):
   - Single Actions panel expanded into tabbed interface: **Actions**, **Pull Requests**, **Issues**
   - Actions tab: workflow runs, jobs, steps (unchanged from original)
   - Pull Requests tab: open PRs with checks, reviews, conflicts, comments; linked Cogpit sessions; closed/merged PRs fold away
   - Issues tab: open issues filtered by assignee/author/label; closed issues fold away; issue-to-composer drop support
   - New helper modules: `Description.tsx`, `parts.tsx`, `time.ts`, `useExpandable.ts`
   - New store: `githubStore.ts` (renamed from `githubActionsStore.ts`)
   - New backend: server routes for actions, issues, PRs, PR files, and PR session links

2. **Per-session cost tracking**:
   - New pricing file: `shared/usageCost/pricing.ts`
   - New service layer: `server/lib/usageCost/{aggregate.ts, service.ts}`
   - New route: `server/routes/usage-cost.ts`
   - New hook: `src/hooks/useSessionUsageCost.ts`
   - New component: `src/components/stats/SessionCostPanel.tsx`
   - Project PR session linking: `server/lib/projectPullRequestSessions.ts`

3. **Removed old stats components** (replaced by new SessionCostPanel):
   - `src/components/stats/ActivityHeatmap.tsx`
   - `src/components/stats/AttributionPanel.tsx`
   - `src/components/stats/InputOutputChart.tsx`
   - `src/components/stats/ModelDistribution.tsx`
   - `src/components/stats/__tests__/AttributionPanel.test.tsx`
   - `shared/session/attributionStats.ts`

4. **New agent capability**: `nestedSubagents` (boolean) in `AgentCapabilities`:
   - True for Codex (nested sub-agents addressed under their own session ID)
   - False for Claude and Copilot (descendants filed under root session)
   - Added to `packages/cogpit-memory/src/lib/agent-descriptors.ts` and synced automatically
