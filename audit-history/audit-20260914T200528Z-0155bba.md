# Video timeline support documentation audit

Date: 2026-09-14
Commit: 0155bba
Verdict: PASS — all documentation drift corrected.

## Summary

This release adds inline video playback to the timeline via markdown image syntax, paired with a new installable skill bundle and enhanced `/api/local-file` route. The changes span three areas: (1) timeline media rendering (LocalVideo component, markdown processor updates), (2) server-side media serving (shared MIME types, HTTP byte-range support, 1 GB video size limit), and (3) skill distribution (new cogpit skill, cogpit-sessions skill description added).

## Changes reviewed

### Timeline components (client)
- New `LocalVideo` component renders `mp4`, `m4v`, `webm`, and `mov` files with controls and seeking via HTTP ranges
- `localMedia.ts` helpers detect and resolve local video paths (same pattern as images)
- Markdown preprocessor promotes bare video paths on their own line (already in use for images)
- `/api/local-file` proxy serves both images and videos with proper MIME types

### Server media serving
- New `shared/mediaTypes.ts` centralizes extension→MIME mappings for server and client (IMAGE_TYPES, VIDEO_TYPES)
- `/api/local-file` route enhanced:
  - New `parseRange()` function implements HTTP `bytes=start-end` header parsing
  - 206 Partial Content responses with `Content-Range` header for seek-capable clients
  - 416 Range Not Satisfiable for invalid ranges
  - MAX_VIDEO_SIZE = 1 GB; MAX_IMAGE_SIZE = 50 MB
  - Response headers include `Accept-Ranges: bytes` and `Content-Length`
- `readableFileRequest.ts` reused for security/size validation

### Skill bundle
- New `.claude/skills/cogpit/SKILL.md` (hand-written entry point)
  - Aggregates cogpit-memory and cogpit-sessions as references
  - "Showing images and videos" section covers markdown syntax, file extensions, CSP limitations, and recording via `agent-browser record`
- New `.claude/skills/cogpit/references/` (generated from source skills by `scripts/sync-cogpit-skill.ts`)
  - `cogpit-memory.md` (byte-copied from `packages/cogpit-memory/skill/SKILL.md`)
  - `cogpit-sessions.md` (byte-copied from `.claude/skills/cogpit-sessions/SKILL.md`)
- `.claude/skills/cogpit-sessions/SKILL.md` gained the frontmatter `description` the Skills CLI requires to list it
