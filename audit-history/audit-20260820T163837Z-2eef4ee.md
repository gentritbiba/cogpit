# Audit report: Mission Control double-tap shortcut

**Date:** 2026-08-20 16:38 UTC
**Commit:** `2eef4ee`
**Status:** PASS AFTER UPDATES

## Scope

Mission Control now opens when the user taps the platform modifier twice in
succession. The default is double Command on Apple platforms and double Ctrl on
other platforms. A modifier used as part of a chord does not count as a tap,
and the two taps must complete within 400 ms. A custom Mission Control chord
still replaces the default gesture.

The keybinding registry now represents the default as a double-tap modifier
shortcut and formats it as `Double ⌘` or `Double Ctrl`. Existing stored chord
overrides remain valid. No API route, server contract, deployment setting, or
external configuration format changed.
